# Shantik V6 · Album 01 Birthday Chibi — Preview D

Based strictly on `Our_Love_Story_Shantik_V6_5_Album_Animasi_Tematik_PREVIEW.zip`.

## Changes scoped to Album 01 only
- Replaced the old birthday cover chibi sticker with a still image from frame 1 of the user-provided 24-frame birthday spritesheet. Clicking this sticker opens the album, as does the original Polaroid album cover.
- Added a larger spritesheet animation inside Album 01's dialog next to the unchanged photographic memories and poetic story; replay with “Putar lagi”.
- JavaScript renders exactly 24 grid cells in row-major sequence, at 10 fps (2.4 seconds), once per opening. It stops on close. Reduced-motion users get the still frame.
- Preserved source art as uploaded. Because its background is white/semitranslucent rather than true transparent alpha, the UI places it on a soft ivory/pink paper and uses multiply blending instead of destructive mask extraction.
- Five albums stay in the gallery (9 original photos + 1 video); all other chibi and site sections are untouched.

## Preview only
No deployment or production Netlify updates performed. To view, open index.html via a local HTTP server or upload to a *non-production* preview environment only with the owner's explicit approval.
