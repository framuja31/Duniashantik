# Shantik V6 — Preview Penyesuaian Animasi 5 Album

STATUS: **PREVIEW LOKAL, BELUM DEPLOY**.

Hanya dekorasi animasi chibi di dalam #gallery yang disesuaikan.
- Ulang Tahun: chibi pelukan asli (gallery-d) + kue dan lilin.
- Batu: chibi berjalan asli (gallery-a) + pegunungan.
- Cilegon: chibi duduk asli (gallery-b) + bus.
- Double Date: chibi bercanda asli (gallery-c) + remote permainan.
- Wallpaper: chibi duduk asli (gallery-e) + rol wallpaper dan rumah.

Semua 15 frame asli pada masing-masing animasi tetap digunakan. Aset SVG tematik dan CSS gerak baru ditambahkan. Bukan animasi chibi baru yang benar-benar melakukan aktivitas tersebut.

Bagian lain di luar galeri, termasuk Hero, Counter Pelukan Rindu, musik, galeri foto/video, tulisan puitis, dan fitur kejutan tidak diubah.

Untuk uji lokal: ekstrak ZIP dan jalankan `python -m http.server 8000`, buka `http://localhost:8000/#gallery`, lalu ketuk chibi pada setiap album.
