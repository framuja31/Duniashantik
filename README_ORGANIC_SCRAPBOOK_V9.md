# Shantik — Organic Romantic Scrapbook (Gabungan A + B)

**Cakupan perubahan:** HANYA layout sampul Galeri Kenangan.

Desktop: grid 12 kolom, kombinasi lebar 3/4/5 kolom, tinggi berbeda, Polaroid, washi tape, kemiringan lembut.

Tablet: dua kolom dengan album utama selebar grid.

Mobile: dua kolom asimetris; Album 1, 6, 9 menjadi featured lebar penuh. Sampul tetap clickable dan chibi existing tetap tersedia.

Isi album: Standard B Adaptive Photo Viewer (contain/no crop), foto/video dan animasi 1–9 tidak diubah.

Tidak ada deploy Netlify.
