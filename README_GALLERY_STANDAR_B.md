# Shantik Gallery Design System V1 — Standard B

- Standar diterapkan pada **kelima album** dalam modal ketika dibuka.
- Bingkai foto menyesuaikan rasio asli foto portrait/landscape/square dengan batas lebar dan tinggi relatif viewport.
- Foto dan video dalam album menggunakan `object-fit: contain`, tidak di-crop.
- Sampul galeri tetap kolase kreatif; sampul Album 4 menggunakan Polaroid bertumpuk dengan foto selfie dan foto The Reds.
- Semua foto/cerita/animasi chibi tetap dipertahankan.
- Navigasi, video dan replay chibi dipertahankan.
- File ini untuk preview lokal, **bukan deployment Netlify**.
